# DN Apps & Automation

One-page portfolio (LT/EN) + admin panelė turiniui redaguoti.

## Greitas startas

```bash
npm install
copy .env.example .env.local
npm run dev
```

- Svetainė: http://localhost:3000  
- Admin: http://localhost:3000/admin
